This is the sample form from XTRA. How would it be used??

  • Make Name, Address and, obviously, Email Address compulsory to discourage frivolous registration. Details like Phone and Fax need not be compulsory. (I believe it should be possible to use Javascript to return the filled-in form to the user for checking before final submission if that facility is not supplied by Xtra; but it seems the redirect facility should enable this).
  • Give the purpose of the Registration, such as:
    • Notification of events
    • Notification of website updates
    • etc.etc.
  • Consider a message on the form such as "You should receive an email from Rogaine NZ within 24hrs to verify that your details are correct. If you don't then try again" (How can this be automated?? Needs a machine permanently on.)
  • Also need an inviting message saying "If your email address changes then don't forget to re-register". (Would use Name, Address to remove the old address. Need to automate this).
  • Want to automate removal from list if emails bounce. Maybe users should be warned of this, but they cannot be notified.
  • Do we want an "Unsubscribe" (ADD/REMOVE) capability on the form? I think so. This could be automated OK by checking against some or all of the fields.
The menu entry could be "Stay in Touch" or similar. "Subscribe" has implications of cost, so I don't like that.
