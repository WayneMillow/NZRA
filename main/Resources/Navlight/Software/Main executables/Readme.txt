You need administrative priviledges to create a folder C:\Program Files\NavLight Rogaine Scoring
Then copy all the files in this folder into it.
Right-click on RogaineSCORE.exe and send to Desktop (Create shortcut).

Run the program, and you should be guided to create a sample event in C:\Users\Public\RogaineEvents.
THere is plenty of HELP available from the menus on many of the windows.
Even if you have no hardware, you can still experiment with event setups etc.
