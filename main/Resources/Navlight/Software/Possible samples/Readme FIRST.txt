To play around with the software, after you have created an Event folder, 
copy TagTeams.txt,PunchNums.txt, and SourceSpreadsheet.xls into that event folder.

You can experiment with Course Setup, to create a 24Hr and a 6Hr courses, and others as you wish.
Play around with changing the Start and Finish times of a course, and the penalty points.
You can also decide whether you use Minimum or Maximum score, for teams whose tags score different values.

When you SAVE your new course information, you create a file called "TagReader_Options.txt".
You can save your new event from the options under the EVENT Menu.

After some practice, copy the TagReader_Options.txt file from here into your event (over-writing your own).
This contains some advanced Courses (duration-limited, Chain) which you might like to explore.

You can also experiment with changing the status of punches as part of the course setup.
The status punches that you will need are BRIEF and FINISH.

You can also try changing the Age/Gender categories.

Try running the spreadsheet, and assigning Tags.
You will need to have a 24Hr and a 6Hr course created in your event or you will get a warning.
If you "write Tagnums.txt" from the spreadsheet, a file called "Tagnums.txt" is created.
Open the Tagnums.txt file and the first few line should be:

TagID	TEAM	CLASS	COURSE	NAMES	HANDICAP	TEAMNAME

START:
 AAAF	1	MV	24Hr	Jack Nicholls, Renee Fleming		The Unlikelies
 AWAH	1	MV	24Hr
 AAAG	2	W	24Hr	Richard the Lionheart, Vivienne Leigh		Shakespear
 AWAJ	2	W	24Hr



Also, a sub-folder called TeamData will be created, 
and a file called "SpreadSheet.txt" will be created in it. 
It should match the one in this Possible Samples collection.
You can then go back to Event Setup and create a link to this file, 
but this is not required if you have used the spreadsheet to create your Tagnums.txt file.

Once the Tagnums.txt file has been created, you can also inspect and modify it in the "TAGS to TEAMS" window,
although the preferred method is to do everything from your spreadsheet.
