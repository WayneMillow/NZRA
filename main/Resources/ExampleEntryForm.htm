Example Entry Form
(Peter Squires, April 2002)

Download:   DOC (Word95) version (20KB)  or  PDF version (8KB)


The following is an example of an entry form, in A4 Landscape format, that is suitable for most Rogaine events. Download the DOC version and modify it to suit your event. Items A and B might be tee-shirts, beer mugs, or similar paraphernalia. "Enquiries" should be directed to a specific event organiser (email address and phone number), but might refer to the Contacts section of this website as well.

(It is not intended that you print this version directly from the website - it is not printer friendly. Rather, download the DOC or PDF versions).
